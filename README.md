# Small scripting and automation jobs

This repository is the public job-request and delivery inbox for **Olly1206**.
It supports small, clearly scoped scripting jobs, with AI assistance and owner
review. It is a working inbox and sample project, not a marketplace or escrow.

Examples of work to request:

- CSV cleanup, date normalization, deduplication and validation reports.
- Small Python or Node.js data-conversion scripts.
- Repeatable file-processing tasks with clear input/output requirements.

## Request a quote

Open a **Paid scripting request** using the Issues form. Include the task, a
synthetic input example, desired output, acceptance criteria and your budget.
Do not post credentials, personal data, private customer files or proprietary
code here. Private material requires a separately agreed delivery route.

You receive a scoped proposal with price, work budget and acceptance checks.
Creating an issue does not accept a job, reserve a delivery date or prove funding.
Work starts after the scope, payment terms and acceptance criteria are agreed.
AI-assisted replies are disclosed and reviewed before publication.

## Payment and delivery

The initial supported payment route is **native USDC on Base mainnet**. Agree the
recipient, amount and timing in the request thread before sending anything.
Ethereum USDC and Base USDC are different networks; do not send to an unconfirmed
route. No checkout, automatic payment or escrow is provided by this repository.

For work suitable for public sharing, the thread carries the agreed delivery
location, how to run it, test results and limitations. Private deliveries need an
agreed private route. The customer checks the result against the agreed criteria.
This inbox does not provide proof of prior paid sales or guaranteed profitability.
